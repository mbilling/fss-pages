SECURE

Locked by default, not by add-on.

TLS 1.3, mTLS and OIDC, deny-by-default ACLs, a hash-chained audit log. Revoking a policy evicts live sessions. Rust with unsafe code forbidden; every parser fuzzed; signed, reproducible builds with SBOM.

RELIABLE

Zero acked messages lost.

Sessions are quorum-replicated by default, so an acknowledged message survives losing a node, even in flight. Grow, shrink and replace nodes with no acked loss. Prometheus, OpenTelemetry, health probes and a Kubernetes operator built in.

CHEAP

Open equals enterprise.

Every feature is Apache-2.0, clustering included, with no paid tier. 75,000 msg/s on one 4-vCPU node, 1.7× Mosquitto and EMQX on the same host. Fewer machines, no licence: the lowest total cost of ownership is the design goal.

HOW IT RUNS

Pull the plug on a node.

Devices publish into a masterless mqttd cluster. Every acknowledged message is already replicated before the ack goes out, so a dead node moves its sessions to the survivors and nothing acknowledged is lost.

GET STARTED

From laptop to cluster in three commands.

1 · Lookfss-mqtt
brew install mbilling/tap/fss-mqtt
fss-mqtt mqtts://broker:8883 -u me \
  -t 'plant/#' -t '$SYS/#'
2 · Trymqttd, one node
docker run -d -p 1883:1883 \
  -e MQTTD_PLAINTEXT_BIND=0.0.0.0:1883 \
  -e MQTTD_ALLOW_ANONYMOUS=1 \
  ghcr.io/mbilling/fss-mqtt-broker
3 · Runsecured cluster
NS=mqttd REPLICAS=3 \
  ./deploy/helm/mqttd/bootstrap.sh
helm install mqttd deploy/helm/mqttd \
  -n mqttd --set replicaCount=3

Step 2 is a first look only: plaintext and anonymous. The secured setup (TLS 1.3, mTLS, ACL) is in the broker guide.
